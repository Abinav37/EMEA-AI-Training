# Smart Home Energy Forecasting

This project will explore household electricity consumption data and use time-series forecasting to predict future power usage.

The main goal is to build a simple LSTM-based model to forecast energy consumption 15 minutes ahead.

## Planned work

- Collect and inspect household energy usage time-series data
- Prepare the data for sequence-based forecasting
- Build and train an LSTM model
- Evaluate forecast accuracy
- Review the model output and next steps

This project is a beginner-friendly learning exercise and is intended to support future forecasting work using time-series data.
